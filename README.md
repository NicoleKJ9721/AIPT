# AIPT 工业视觉 AI 检测平台

面向工业场景的端到端 AI 训练与部署平台，覆盖数据导入、标注、训练、评估与模型导出全流程。

## 平台功能

1. **数据导入与预处理**
   - 支持批量导入图片集。
   - 支持按比例划分训练集/验证集/测试集。
   - 提供数据集统计与概览（数量、标注状态、类别分布）。

2. **标注功能**
   - 支持目标检测、分类、分割、OBB（旋转框）标注模式。
   - 支持标注格式导入/导出（如 COCO、YOLO 等）。

3. **数据集版本管理与增广**
   - 支持数据集快照/版本管理，确保实验可追溯。
   - 支持常用数据增广策略配置与预览。

4. **模型训练**
   - 支持 YOLO 系列模型（可扩展到多种规模）。
   - 支持超参数设置与自动调参。
   - 支持训练设备选择（CPU/GPU/MPS）。

5. **训练过程与模型评估**
   - 训练过程可视化监控（loss、mAP、F1 等）。
   - 模型能力评估与多版本对比。

6. **模型导出与部署**
   - 支持导出 ONNX/TensorRT/NCNN/OpenVINO/CoreML 等格式。
   - 支持工控机推理部署配置输出。

## 安装方法

> 目前为后端基础脚手架，优先支持本地开发环境安装。

### 1. 环境要求
- Python 3.10 及以上
- 推荐使用虚拟环境（venv/conda）

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动服务
```bash
uvicorn backend.app:app --host 0.0.0.0 --port 8000
```

### 4. 健康检查
```bash
curl http://localhost:8000/health
```

预期返回：
```json
{"status": "ok"}
```

## 注意事项

1. **依赖安装**
   - 需要确保 `fastapi`、`uvicorn`、`pydantic` 等依赖可用。
   - 如需运行测试，请确保已安装 `pytest` 与 `httpx`。

2. **数据与模型路径**
   - 当前示例数据为占位符路径 `/data/demo`，请根据实际环境配置数据集路径。

3. **硬件支持**
   - Windows：推荐 NVIDIA GPU + CUDA 环境。
   - macOS：支持 Apple Silicon（M 系列）与 MPS/Metal。

4. **生产部署**
   - 建议使用反向代理（如 Nginx）并配置 HTTPS。
   - 大规模训练任务请配置任务队列与日志系统。
