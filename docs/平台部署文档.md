# AIPT 平台部署文档（Windows）

本文档面向 **Windows 10/11（x64）** 环境，提供从零开始的前后端部署与验证步骤，按命令执行即可完成部署。

## 0. 本机测试环境（用于验证本平台可运行）

以下为本仓库在当前测试设备上的实际信息（用于复现实验环境，不需要完全一致）：

- 操作系统：Microsoft Windows 11 家庭中文版（64 位），Build `26100`
- 设备：LENOVO `83DG`，x64-based PC
- CPU：Intel(R) Core(TM) `i7-14700HX`（20C / 28T）
- 内存：约 `32 GB`
- 显卡：NVIDIA GeForce RTX 4070 Laptop GPU（Driver `32.0.15.6624`）
- Node.js：`v24.12.0`（npm `11.6.2`）
- Python：`3.11.7`（本机 `python` 指向 `D:\APPS\Environments\Anaconda3\python.exe`）

默认端口：

- 后端：`8000`（FastAPI）
- 前端：`5173`（Vite Dev Server）

## 1. 目录结构与启动方式

- `backend/`：FastAPI 后端（含测试用例 `backend/tests/`）
- `frontend/`：React + Vite 前端
- `start_services.bat`：推荐（GUI 启动器，自动拉起前后端并打开浏览器）
- `start_services_cli.bat`：命令行方式启动（便于查看日志/调试）
- `logs/`：启动器/服务日志输出目录

## 2. 安装前置软件（建议使用 winget）

在 PowerShell（建议管理员）执行：

```powershell
winget install --id Git.Git -e --source winget
winget install --id OpenJS.NodeJS.LTS -e --source winget
winget install --id Python.Python.3.11 -e --source winget
```

可选：如遇到 `torch`/DLL 相关错误，再安装 VC++ 运行库：

```powershell
winget install --id Microsoft.VCRedist.2015+.x64 -e --source winget
```

说明：

- 若你已经安装了 Git / Node / Python，可跳过对应步骤。
- 本平台默认使用端口 `8000/5173`；如被占用请先释放或修改启动脚本参数。

## 3. 获取代码

如果你通过 Git 获取：

```powershell
git clone <你的仓库地址> AIPT
cd AIPT
```

如果你拿到的是压缩包：解压后在 PowerShell 进入解压目录即可（确保路径中没有过深的层级，避免 Windows 路径长度问题）。

## 4. 创建“纯净”后端虚拟环境（推荐 repo-local venv）

在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -U pip
.\.venv\Scripts\python -m pip install -r .\backend\requirements.txt
```

验证后端依赖是否安装完成：

```powershell
.\.venv\Scripts\python -c "import fastapi,uvicorn,sqlalchemy; import PIL; import torch; import ultralytics; print('OK')"
```

## 5. 安装前端依赖

```powershell
cd .\frontend
npm install
```

（可选）验证前端可构建：

```powershell
npm run build
```

## 6. 启动平台

### 方式 A：一键启动（推荐）

直接双击 `start_services.bat`：

- 自动启动 GUI 启动器
- 自动检查/安装依赖（后端 pip、前端 npm）
- 自动拉起后端（`8000`）与前端（`5173`）
- 自动打开浏览器进入平台页面

### 方式 B：命令行启动

在仓库根目录执行：

```powershell
cmd /c start_services_cli.bat
```

### 方式 C：手动分别启动（调试）

后端（新开 PowerShell）：

```powershell
cd <AIPT仓库根目录>
.\.venv\Scripts\python -m uvicorn backend.main:app --reload --reload-dir backend --host 127.0.0.1 --port 8000
```

前端（新开 PowerShell）：

```powershell
cd <AIPT仓库根目录>\frontend
npm run dev
```

打开：

- 前端：`http://localhost:5173`
- 后端接口文档：`http://localhost:8000/docs`

## 7. 自动化测试（建议部署完成后先跑一遍）

后端测试（仓库根目录）：

```powershell
.\.venv\Scripts\python -m pytest -q
```

前端构建（`frontend/`）：

```powershell
cd .\frontend
npm run build
```

## 8. GPU 加速（可选，仅 NVIDIA）

默认 `backend/requirements.txt` 会安装 **CPU 版** PyTorch（通用、体积更小）。如需要 CUDA 推理/训练（下载体积较大，可能超过 2GB），可在 venv 中执行：

```powershell
.\.venv\Scripts\python -m pip install --upgrade --index-url https://download.pytorch.org/whl/cu121 torch==2.2.1+cu121 torchvision==0.17.1+cu121
```

说明：

- 若你希望使用其它 CUDA 版本，请参考 PyTorch 官方安装指引选择对应 index-url。
- CUDA 版安装完成后，建议执行 `.\.venv\Scripts\python -c "import torch; print(torch.cuda.is_available())"` 验证。

## 9. 常见问题排查

### 9.1 端口被占用（8000 / 5173）

启动器会尝试释放端口。如仍有占用，可手动查看并结束进程：

```powershell
Get-NetTCPConnection -LocalPort 8000,5173 -State Listen | Select-Object LocalPort,OwningProcess
```

### 9.2 前端启动弹出 `npm.ps1` / 执行策略提示

平台启动脚本已尽量使用 `npm.cmd` 避免触发 `npm.ps1`。如你手动运行遇到策略限制，可临时允许当前进程执行脚本：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 9.3 依赖安装失败

- 后端依赖日志：`logs/backend_install.log`、`logs/backend_install.err.log`
- 前端依赖日志：`logs/frontend_install.log`、`logs/frontend_install.err.log`

建议先确认网络可访问，再重试安装。
